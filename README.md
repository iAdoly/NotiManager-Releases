# Notification Filter

مستودع إصدارات التطبيق وملفات التثبيت. يحتوي على دليل الاستخدام وملفات APK في Releases؛ كود المشروع محفوظ في مستودع خاص منفصل.

## التحميل

[تحميل آخر إصدار](https://github.com/iAdoly/NotiManager-Releases/releases/latest)

الإصدار الحالي: **0.8.6 — build 9**.

## المتطلبات والتثبيت

- Android 13 أو أحدث (API 33+).
- حمّل ملف APK من قسم Assets في صفحة الإصدار وافتحه للتثبيت. قد يطلب Android السماح بالتثبيت من التطبيق الذي فتحت منه الملف.
- بعد التثبيت، أكمل إعداد التطبيق وفعّل الوصول إلى الإشعارات لتشغيل القواعد.

## الميزات

- قواعد لمطابقة الإشعارات حسب المصدر والنص والشروط المختارة.
- تنبيهات مخصصة، تهدئة، إزالة، تأجيل وتذكير، مع إعدادات مستقلة لكل إجراء.
- تتبع بلاغات اختياري من المصادر المختارة، مع البحث والإغلاق المحلي والتراجع.
- استيراد وتصدير محلي للإعدادات والبيانات المدعومة.
